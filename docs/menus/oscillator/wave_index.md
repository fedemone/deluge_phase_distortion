Index into the wavetable.

This is in the standard 0-50 range, but modulation can reach values between the increments presented by this menu item.
LFO modulation with depth 50 can always reach the full range of wavetable indices.

For <string-for name="STRING_FOR_PHASE_DISTORTION">PHASE_DIST</string-for> and
<string-for name="STRING_FOR_VPS">VPS</string-for> oscillators this is shown as
<string-for name="STRING_FOR_DCW">DCW</string-for>: how far the waveform is bent, from a pure sine at 0.
